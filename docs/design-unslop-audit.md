# 디자인 시스템 점검 — unslop 기준 (2026-11-08)

상태: 2026-11-08 대표 결정 1~7 전부 권장안 → 같은 날 적용(베타). 전후 비교 스크린샷은 대화 기록.
대상: `app/globals.css`(:root 토큰·공용 .sm-*·사이드바), `app/b2b/b2b.css`(.b2b-* 컴포넌트), `docs/design-system.md`.
기준: unslop 스킬(Damir Sokolovsky, CC BY 4.0)의 signs·tokens·9패스. 스킬 자체 규칙대로 "이미 좋은 시스템이면 값은 두고 쓰임새만 고친다"를 지켰다.

## 1. 판정 — 가벼운 슬롭, 템플릿 룩 쪽

unslop 의 '슬롭 신호' 대부분은 없다. 그라데이션·글로우·색 그림자·이모지 아이콘·펄스·transition-all·hover:scale 이 0건이고, 유채색은 주황·빨강·초록 셋뿐, 간격은 4px 토큰, 숫자는 tabular, 초점 링과 reduced-motion 까지 있다. 2026-10-14~17 결정이 이미 unslop 의 80% 를 해 놓았다.

남은 것은 두 갈래다.
- **굵기와 자간이 무겁다.** 700 이 기본 굵기처럼 쓰인다(CSS 72곳 + 인라인 161곳, 800 이 44곳). 작은 제목에 음수 자간. unslop: 400·500, 600 은 드물게, 자간은 40px 넘는 글에만 음수.
- **방향(캐릭터)이 적혀 있지 않다.** Pretendard + 회색 + 주황 1차 버튼은 '정돈된 템플릿'의 기본값이다. 이 제품만의 한 문장·세계·모먼트·시그니처가 문서에 없어, 화면마다 같은 모양이 나온다. unslop 이 "깨끗하지만 어느 제품이어도 되는 화면"이라 부르는 상태.

`transition` 은 color·background·border·transform·opacity 만, 사이드바 폭 1곳(의도된 모션 3개 중 하나). 그림자는 중립 2종. 토스트 등장 1개, 스피너는 살아 있는 것이라 허용. 바꿀 것 없음.

## 3. 방향 제안 — 문서에 없던 다섯 줄

unslop 은 고치기 전에 방향 다섯 줄을 쓰라고 한다. 지금 시스템엔 이것이 없어서 모든 화면이 같은 회색 표가 된다. 제안값이며 대표가 단어를 바꿔야 맞는다.

- **제품**: 냉동 순살 생선을 파는 작은 팀이 하루 운영(발주·재고·고객 메시지·매출)을 보는 도구.
- **캐릭터**: 차분하고, 정확하고, 조금 따뜻하다. ('깔끔·모던·미니멀' 금지 — 어떤 템플릿이든 그렇게 말한다)
- **세계**: 얼음 위의 생선과 종이 전표. 차갑고 흰 바탕에 따뜻한 손글씨 한 줄. 중립 램프는 지금의 흑백(그래파이트)을 유지하고, 주황은 손이 닿는 한 곳에만.
- **모먼트**: 숫자. 매출·재고·클릭률 KPI 와 추세 차트가 화면에서 유일하게 풍부해지는 곳. 그 밖의 크롬(네비·버튼·표)은 더 조용해진다.
- **시그니처**: 현재 위치를 가리키는 주황 점(사이드바·탭·세그먼트). 지금 '주황 채움 + 흰 글자'로 넓게 쓰는 것을 작은 점 하나로 줄이면, 주황이 드물어져 오히려 눈에 띈다.

## 4. 제안 — 값까지

### A. 글 굵기 한 단계 내리기 (가장 큰 변화, 가장 적은 코드)
| 지금 | 제안 | 적용 |
|---|---|---|
| 제목 700 | 600 | `.b2b-page-title` `.b2b-card-title` `.b2b-modal-title` `.home-*` 제목·`.crm-*` 제목 |
| 라벨·버튼·탭·네비 600 | 500 | `.b2b-field-label` `.b2b-btn-*` `.sm-tab` `.app-sb-tool` `.b2b-status-pill`(700→500) |
| KPI 값 700/800 | 600 | `.b2b-stat-card-value` `.sm-stat-hero-total` |
| 글자 로고 800 | 600 | `.app-sb-brand` `.app-topbar-brand` |
| 인라인 `fontWeight: 700/800` 202곳 | `.sm-strong`(600) 한 클래스로 치환, 800 은 전부 600 | 코드모드 1회 |
- 굵기 규율: 400 본문 · 500 라벨·버튼 · 600 제목·KPI. 700 이상 없음. design-system.md 의 "400·600·700, 800 은 KPI" 줄을 바꾼다.
- Pretendard Variable 이라 500 이 실제로 렌더된다(가변 폰트).

### B. 자간·대문자
- `--sm-ls-heading: 0` (24px 이하에 음수 자간 없음). 40px 넘는 글이 없으니 토큰 자체를 지워도 된다.
- `--sm-ls-label: 0.02em` 은 12px 회색 라벨에만 유지(unslop 허용).
- `text-transform: uppercase` 3규칙 + 인라인 2곳 제거. SKU 는 데이터 그대로 보인다.

### C. 주황을 한 자리로 — 대비 문제와 같이 해결
| 지금 | 제안 |
|---|---|
| 1차 버튼: 주황 채움 + 흰 700 14px (3.36:1) | **검정 채움(#1A1A1A) + 흰 500 13px** 또는 **어두운 주황 #C8431C 채움 + 흰 500**(4.91:1). unslop 의 라이트 테마 기본은 전자. 주황을 '현재 위치 점'에만 쓰려면 전자, 브랜드 색을 버튼에 남기려면 후자 |
| 활성 탭: 주황 채움 + 흰 700 | 검정 글자 500 + 연주황 바탕 + 왼쪽 주황 점(시그니처) |
| 사이드바 현재 위치: 주황 글자 700 (3.15:1) | 검정 글자 500 + 연주황 바탕 + 왼쪽 주황 점 6px |
| `--sm-bg-warm` 표면 3곳 | 즐겨찾기 블록 1곳만 남기거나(색면으로 고정 구역 표시) 전부 `--sm-bg-subtle` + 헤어라인 |
- 결과: 주황은 1차 버튼(후자 선택 시)·현재 위치 점·로고. 화면의 2% 이내.

## 5. 영향·비용
- 전부 CSS 토큰·공용 클래스 값 변경이라 **화면 코드 변경은 거의 없다**(인라인 굵기 코드모드와 ✕ 아이콘 치환만). 데이터·API 무관.
- 굵기·주황 축소는 **전 화면 모양이 한 번에 바뀐다**. 직원이 "뭔가 흐려졌다"고 느낄 수 있어 업데이트 노트에 한 줄.
- 1차 버튼 색은 브랜드 결정이라 대표가 고른다(아래 1번).
- 작업량: A~F 0.5일, 코드모드·확인 0.5일, 문서 0.25일. 베타에서 5개 화면(홈·발주·재고·CRM·리포트) 스크린샷 비교 뒤 운영.

## 6. 대표 결정
1. 1차 버튼: (가) 검정 채움 + 흰 글자, 주황은 현재 위치 점·로고에만(unslop 기본, 권장) / (나) 어두운 주황 #C8431C 채움 + 흰 글자(브랜드 색 유지, 4.91:1) / (다) 지금 그대로(#F15A30, 3.36:1, 700 보정 유지).
2. 현재 위치(사이드바·탭·세그먼트): (가) 검정 글자 500 + 연주황 바탕 + 주황 점(권장) / (나) 지금처럼 주황 채움·주황 글자.
3. 굵기: (가) 400·500·600 세 단계, 700 이상 없음(권장) / (나) 제목만 700 유지.
4. 모서리: (가) 컨트롤 8 통일 + 알약 폐지(배지 6·select 8)(권장) / (나) 버튼 12 유지, 알약만 정리 / (다) 그대로.
5. `--sm-bg-warm` 표면: (가) 즐겨찾기 블록 1곳만(권장) / (나) 전부 중립으로 / (다) 그대로.
6. 방향 다섯 줄: §3 제안 그대로 쓸지, 캐릭터·세계·시그니처 단어를 바꿀지 — 바꿀 단어가 있으면 적어 주세요.
