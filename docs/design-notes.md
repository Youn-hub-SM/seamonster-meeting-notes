(내장 브라우저 창이 800px 이라 1440px 은 축소되어 못 읽는다 — 1100px 이 상한. 큰 모니터 화면은 대표 캡처로 본다.)

### 바로 고친 것
- **KPI 값이 자릿수 중간에서 꺾임** — 재고 목록 '46,339,65 / 6', 배송일지 '31,468,72 / 2원'. 원인은 body 의 `overflow-wrap: anywhere`(한글 줄바꿈 규칙)가 숫자에도 적용. `.b2b-stat-card-value { white-space: nowrap }`. 표 숫자 열은 10-14 에 같은 이유로 고쳤는데 KPI 는 빠져 있었다.
- **발주 목록 날짜 열이 '2026-…'로 잘림** — 열 폭을 %로 바꾼 뒤(10-14) 1100px 창에선 8% = 70px 이라 날짜 10자가 안 들어갔다. 날짜 두 열만 px(84·104)로 되돌림. 교훈: 글자 수가 고정된 열(날짜·상태)은 px, 가변 글자(업체·품목)만 %.

### 적어 둔 것(기획 1~4차에서 처리)
- 즐겨찾기 'B2B · 발주', 'VOC 관리 · VOC 처리' — 중점 메타 문자열(스킬 티). 1차 A2.

- 배송일지 표의 '도착보장' 수치가 주황 글자 — 값의 뜻(이상·완료)이 아니라 분류 표시로 색을 쓴 곳. 색 규칙(유채색은 뜻이 있을 때만) 위반. 2차.
