# CRM 메시지맵 개편 기획 — 1단계: 트리거·D+n·발송 수·목표 클릭률 (2026-10-27)

대표 결정(2026-10-26):
- **추적 메시지(utm 단 것)** 는 utm 위주로 추적하고 목표는 **클릭률 개선**(클릭 = 우리 의도가 전달됐는지의 척도).
- **메시지맵 전체**는 메시지 **피로도·중복**을 피하기 위한 수단 — 전체를 줌인·줌아웃할 수 있는 맵.
- 솔라피는 API 자동, 나머지 발송 수는 손으로, 데이터라이즈·블룸 CSV 업로드는 보류.

이 문서는 그중 **1단계**(메시지에 구조화 칸을 넣고 기존 30개를 채우는 것)의 기획이다. 2·3단계는 끝에 요약.

## 1. 왜 칸을 늘리나

지금 메시지의 "발송시점"은 자유 글("결제 후 1시간", "60일 경과", "상시")이라 **한 고객이 며칠에 몇 통을 받는지** 계산할 수 없다.
피로도·중복을 보려면 메시지마다 "무슨 사건 뒤 며칠째"가 숫자로 있어야 하고, 클릭률을 보려면 발송 수가 있어야 한다.

## 2. 메시지에 추가하는 칸 (migration 150)

| 칸 | 뜻 | 값 |
|---|---|---|
| `trigger` | 기준 사건 | signup(가입) · first_order(첫 구매) · reorder(재구매) · shipped(출고) · delivered(배송 완료) · cart(장바구니 이탈) · subscription(정기배송 회차) · inactive(마지막 구매 후 경과) · event(행사·기획전) · always(상시·수동) |
| `offset_days` | 기준 사건 뒤 며칠째(정수, 음수 = 전) | 0 = 당일. "결제 후 1시간" 은 0, "마감 3일 전" 은 -3 |
| `offset_note` | 숫자로 못 담는 조건 | "2회 구매 시점", "재구매 주기 도래" 처럼 사람이 읽을 보조 글(선택) |
| `tracked` | 추적 메시지 여부 | **자동**: `links.utm_campaign` 이 있으면 true. 따로 켜고 끄지 않는다 |
| `utm_medium` | GA 매체(149 에서 추가됨) | 규칙 '메시지종류-경로', 예 alimtalk-naver · brandmessage-cafe24 |
| `target_ctr` | 목표 클릭률(%) | 비우면 목표 없음. 표에서 실제 클릭률과 색으로 비교 |
| `solapi_template_id` | 솔라피 템플릿 ID | 솔라피로 보내는 메시지만. 이 값으로 발송 수가 자동으로 붙는다 |

발송 수·클릭은 메시지 칸이 아니라 **149 의 crm_send_stats** 에 날짜별로 쌓는다(솔라피 자동, 나머지 직접 입력). 메시지와는 `template`(= 메시지 제목 또는 솔라피 템플릿 ID) 로 잇는다.
지금 있는 `perf`(sent·clicked 손입력 jsonb)는 **쓰지 않는다**(화면에서 숨김, 데이터는 둠).

클릭률 정의: **GA 세션 ÷ 발송 수**. 클릭은 도구마다 기준이 달라 GA 세션으로 통일한다(앱 안 브라우저 등으로 10~20% 적게 잡히므로 절대값보다 추이·비교용). 같은 메시지의 A/B 는 `utm_content` 로 가른다.

## 3. 기존 메시지 초안 매핑 (시드 30개 기준 — DB 의 현재 값으로 다시 읽어 채운다)

| 단계 | 메시지 | trigger | D+n | 비고 |
|---|---|---|---|---|
| 유입/인지 | 체험단 안내 링크 | event | 0 | 선정 시 |
| | SNS 광고 > 랜딩 · 블로그/가이드 SEO | always | — | 메시지가 아니라 유입 경로. 맵에서 '상시' 띠로만 |

초안은 제가 채우고 **대표가 표(편집) 탭에서 훑어 고치는** 방식. 틀린 매핑보다 빈칸이 낫다고 보면 비워 둔다.

## 4. 화면 변경 (1단계 범위)

- **표(편집) 탭**: 트리거(선택)·D+n(숫자)·조건 메모·utm_medium·목표 클릭률·솔라피 템플릿 ID 열 추가. 발송시점 자유 글은 남기되 D+n 이 있으면 그걸 우선 표시.
- **흐름 탭 카드**: "트리거 D+n" 칩 + 추적 메시지면 ⌁ 표시와 최근 4주 클릭률.
- **주간 성과 탭(기존)**: 수단별 표 아래에 **추적 메시지별 표** 추가 — 메시지 · 매체 · 발송 · 클릭(GA 세션) · 클릭률(목표 대비 색) · 구매 · 매출. 발송 수는 솔라피 템플릿 ID 매핑 → 자동, 없으면 그 주 직접 입력값.
- 메시지 추가/수정 창에 같은 칸. 안내 문구 없음(대표 규칙).

## 5. 2·3단계 요약 (이 문서 밖)

- **2단계 메시지별 클릭률 표** 고도화: 메시지 × 주 추이, 목표 미달 강조, utm_content A/B 비교.
- **3단계 줌 맵**: 전체(고객군 × 트리거 격자, 칸마다 통수) → 타임라인(가로 D+n, 세로 고객군·채널, 겹침 경고) → 메시지(본문·링크·성과). 피로도 규칙 초안: 7일 안 3통 이상, 같은 날 2통, 같은 트리거·같은 날 다른 채널 2통.

## 6. 정해 주실 것

1. 트리거 목록(§2) 이대로 괜찮은지, 빼거나 더할 것.
2. 클릭률 = GA 세션 ÷ 발송 수 로 통일하는 데 동의하는지(도구의 클릭 수는 참고값).
3. 기존 `perf` 손입력 칸을 화면에서 숨겨도 되는지.
4. 시드가 아니라 DB 의 현재 메시지 목록으로 매핑 초안을 채울 테니, 지금 메시지맵에 없는 메시지(예: 월간 브랜드 소식, 기획전 톡채널)를 1단계에서 함께 등록할지.
