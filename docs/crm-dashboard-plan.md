# CRM 대시보드 개편 기획 (2026-10-26)

대표 요청: CRM 대시보드를 다시 짠다. **최대한 API 로, 안 되면 간단한 CSV 업로드로** 수치를 모은다(구글 시트 손작업 대체).

## 1. 수치가 나오는 곳과 수집 방식

| 발송 수단 | 지금 | 새 방식 | 근거 |
|---|---|---|---|
| 솔라피(스마트스토어 알림톡·브랜드메시지) | 발송 내역 CSV → 시트 | **API 자동**(`GET /messages/v4/list`, 카카오 템플릿 ID·수신일시로 집계) | 공개 REST API, HMAC 키 인증 |
| 데이터라이즈 브랜드메시지 | 메시지 통계 > 다운로드(일별) → 시트 | **CSV 업로드**(일별 파일 그대로) | 공개 API 없음(2026-10 확인) |
| 데이터라이즈 알림톡 | 위와 같음 | **CSV 업로드** | 위와 같음 |
| 블룸 AI 알림톡 | 템플릿별 엑셀(일별 없음) → 주 단위 시트 | **엑셀 업로드 + 주 시작일 지정**(주 단위 행) | 공개 API 없음 |
| 랜딩 성과(세션·구매·매출) | 데이터 스튜디오(GA) | **GA4 API 자동** — utm 규칙(source=kakao, medium=종류-경로, campaign=목적) | GA 연결됨(ga.ts) |
| 네이버 톡톡·톡스토어 마케팅 메시지·알리고 문자(라운지) | 기록 없음 | **발송 기록 직접 입력**(발송일·수단·대상·건수·메모) — API·내보내기 없음 | — |

utm 규칙은 메시지맵의 메시지마다 `utm_campaign`(이미 있음) + **`utm_medium`**(새 칸)으로 기록해 GA 수치와 자동으로 잇는다.

## 2. 데이터 모델 (migration 149)

`crm_send_stats` — 수단별 발송·반응 사실(일별 또는 주별 한 줄)
- `source` text: datarize_brand · datarize_alimtalk · blumn · solapi · naver_talk · talkstore · sms · other
- `grain` text: day | week(주 시작일=월요일)
- `date` date: 그 날 또는 주 시작일
- `template` text: 템플릿/캠페인 이름(또는 카카오 템플릿 ID)
- `sent` int, `delivered` int null, `clicked` int null, `cost` numeric null
- `utm_campaign` text null(연결용), `note` text, `batch` text(업로드 묶음), `created_by`, `created_at`
- unique (source, grain, date, template) — 같은 파일을 다시 올려도 덮어쓴다(중복 없음)

`crm_messages` 에 `utm_medium` text 추가.

## 3. 화면 (/crm)

1. **주간 성과**(기본 탭): 주 선택 → 수단별 표(발송·클릭·클릭률·GA 세션·구매·매출·구매전환율) + 최근 12주 추이. 수단 행을 펼치면 템플릿별.
   - GA 열은 utm_medium(=수단) 으로 자동 붙임. 솔라피는 [지금 가져오기] 버튼 + 화면 열 때 하루 지났으면 자동.
   - 업로드: [CSV 올리기] → 수단 고르기(데이터라이즈 브랜드/알림톡·블룸) → 미리보기(행 수·기간) → 등록. 블룸은 주 시작일 입력.
   - 직접 입력: 네이버 톡톡·톡스토어·문자는 한 줄 추가(날짜·대상·건수·메모).
2. **캠페인**: utm_campaign 별 GA 성과(세션·구매·매출)와 그 캠페인에 묶인 메시지·수단·발송 수.
3. **메시지맵**: 지금 흐름·표(편집) 그대로. 손으로 적던 perf(발송·클릭) 칸은 숨기고 수집 수치로 대체.
4. **브랜드 소식**: 월별 기록(공식몰·스마트스토어·톡스토어) — 발송 기록과 같은 표의 '월간 소식' 태그로 거른다(별도 표 없음).

운영 절차 글(솔라피 자동화 경로, 톡스토어 기획전 순서, 데이터라이즈 OR 오디언스·쿠폰 발급 기능)은 매뉴얼 사이트 'CRM' 묶음으로 옮기고 화면에서 링크.

## 4. 단계

1. (이번) 모델·솔라피 API 수집·GA 수단별 집계·주간 성과 표·직접 입력. 솔라피 키(API Key·Secret) 는 Vercel env `SOLAPI_API_KEY`·`SOLAPI_API_SECRET`.
2. CSV 업로드 — **데이터라이즈 브랜드메시지·알림톡 일별 파일, 블룸 템플릿별 엑셀 각 1개 샘플이 필요**(열 이름으로 파서를 맞춘다).
3. 캠페인 탭, 메시지맵 utm_medium, 시트 과거 데이터 1회 가져오기.
4. 매뉴얼 사이트 CRM 묶음.

## 5. 정한 것·안 정한 것
- 정함: API 우선, 안 되면 CSV(2026-10-26 대표).
- 미정: 주간 성과표 지표 7개 확정 여부, 구글 시트 중단 시점, 솔라피 키 발급 담당.
