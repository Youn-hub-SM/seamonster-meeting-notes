# 파도소리 ERP 대체 기획안 (전체 그림)

- 작성일: 2026-11-20
- 대표 방침: ERP 를 더 쓰지 않고 pdsr.kr 로 옮긴다. 한동안 둘 다 쓰다가 전환한다.
- 상태: 전체 그림. 단계마다 세부 기획안을 따로 내고, 대표가 실행이라고 한 단계만 만든다.

## 1. 확인된 것

| 질문 | 답(2026-11-20 대표) |
|---|---|
| ERP 에서 지금 쓰는 기능 | 출고증 인쇄, 거래명세서 출력, 미수금·미지급금 관리, 손익·마진 확인 |
| 쓰지 않는 기능 | 세금계산서 발행 |
| 주문 받은 날 만들어 나가는 물량을 누가 적는가 | 사무실에서 PC 로 |
| 전환 방식 | 한동안 둘 다 쓰다가 전환 |

## 3. 단계

앞 단계가 뒤 단계의 바탕이 된다. 병행 기간에는 단계가 끝날 때마다 ERP 와 숫자를 맞춰 본다.

### 1단계. 거래처와 주문 출고

ERP 에서 가장 많이 쓰는 일이고, 이것이 없으면 다른 것을 옮겨도 ERP 를 끌 수 없다.

- **거래처 목록**: 매출처·매입처를 등록한다(상호, 사업자번호, 대표자, 주소, 연락처). 지금 자유 입력으로 적힌 이름을 목록으로 모은다.
- **주문 출고 입력**: 사무실 PC 에서 날짜와 거래처를 고르고 품명·규격·단위·수량·단가를 줄줄이 적는다.
  - 그 거래처에 전에 보낸 품명·규격·단가가 자동으로 뜬다.
  - 줄마다 "창고에서 꺼냄"과 "그날 만듦"을 가른다. 창고에서 꺼낸 줄만 재고에서 빠진다.
  - 엑셀이나 주문서를 붙여 넣어 한꺼번에 넣는 방법도 본다(하루 60줄).
- **출고증 인쇄**: 주문 출고 한 건을 현장용 출고증으로 뽑는다.
- **거래명세서 출력**: 거래처·기간을 골라 거래명세서를 뽑는다.

### 2단계. 매입

- 원물 매입을 매입처·품명·수량·단가로 적는다. 창고로 들어가는 것과 사 온 날 바로 현장으로 가는 것을 가른다(3년 기록에서 매입의 86%가 바로 현장으로 갔다).
- 매입 내역서 출력이 필요한지는 그때 정한다.

### 3단계. 미수금·미지급금

- 거래처별 원장: 매출·매입 금액이 쌓이고, 입금·지급을 적으면 잔액이 줄어든다.
- 전환 시점의 거래처별 잔액을 기초값으로 넣는다.
- ERP 의 월말 `잔액분리` 처리(우리들F&B 에 34건, −20.7억 원)가 무엇인지 확인해야 같은 방식으로 맞출 수 있다.

### 4단계. 손익·마진

- 품목·거래처·기간별 매출액, 원가, 이익을 본다.
- ERP 는 매출 줄에 매입단가를 적어 손익을 내는데, 3년 기록에서 매입단가가 적힌 줄은 5분의 1뿐이다. 원가를 어떻게 잡을지(상품마스터의 kg당 원가, 매입단가, 수율 반영)를 먼저 정해야 한다.

### 5단계. 대조와 전환

- 같은 기간을 pdsr.kr 과 ERP 에서 각각 엑셀로 뽑아 일자·품목·거래처별 합계를 견주는 화면을 만든다.
- 한 달 이상 어긋나지 않으면 ERP 입력을 멈춘다.
- [예상] 화면이 엑셀 올리기 없이 pdsr.kr 기록에서 바로 읽도록 바꾼다.

## 4. 단계별 크기와 필요한 자료

| 단계 | 크기 | 대표께 받아야 하는 것 |
|---|---|---|
| 1. 거래처·주문 출고 | 가장 큼 | 출고증과 거래명세서 실물(사진이나 PDF), 거래처 목록 엑셀, ERP 주문 입력 화면 캡처 |
| 2. 매입 | 작음 | 매입 입력 화면 캡처 |
| 3. 미수금·미지급금 | 큼 | 거래처 원장 화면 캡처, 잔액분리 처리 설명, 전환 시점 잔액 |
| 4. 손익·마진 | 중간 | 지금 보는 손익 화면 캡처, 원가를 잡는 기준 |
| 5. 대조·전환 | 중간 | 없음 |

## 5. 미리 정해야 하는 것

| 번호 | 정할 것 | 왜 먼저인가 |
|---:|---|---|
| 1 | 금액을 누가 볼 수 있는가 | 지금은 모든 계정이 단가를 적는다. 미수금·손익은 현장 계정에 보이면 안 될 수 있다. 사무실 계정 구분이 필요해진다 |
| 2 | 세금계산서와 회계 | ERP 에서 발행하지 않는다면 어디서 하는지, pdsr.kr 에서 어떤 자료를 뽑아 줘야 하는지 |
| 3 | 부가세 | 3년 기록에 부가세가 적힌 줄은 165건뿐이다(면세 수산물). 과세 품목이 있다면 처리 방식 |
| 4 | 품명과 규격 | 주문 출고는 줄마다 규격이 다르다(2,900종). 규격을 자유 입력으로 둘지, 거래처별로 쓰는 규격을 등록할지 |
| 5 | 백업 | ERP 를 끄면 pdsr.kr 이 유일한 장부다. 정기 백업과 내려받기를 어떻게 둘지 |

## 6. 권하는 순서

1단계부터 한다. 출고증과 거래명세서 실물, 거래처 목록, ERP 주문 입력 화면을 받으면 1단계 세부 기획안을 쓴다. 양식을 보지 않고 만들면 현장에서 쓰던 것과 달라 다시 만들게 된다.

## 7. 지금까지 만든 것과의 관계

- **기록 구분·보관처·단가·이동**(factory/011): 그대로 바탕이 된다. 주문 출고에서 "창고에서 꺼냄"인 줄은 이 기록으로 저장된다.
- **ERP 양식 엑셀 추출**: 병행 기간의 대조 도구로 쓴다. ERP 를 끈 뒤에는 필요 없어진다.
- **[예상] 화면**: 지금은 ERP 엑셀을 올려 쓴다. 5단계에서 pdsr.kr 기록을 직접 읽게 바꾼다.
- **분석 보고서의 "주문 받은 날 만든 생산"**: 1단계의 "그날 만듦" 줄이 이 물량이다.
