# UTM 만들기 — CRM 메시지 규칙 반영 기획안

작성 2026-11-06 · 상태: 2026-11-06 대표 결정 1~7 전부 (가) 확정, 구현 중
배경: CRM 메시지 UTM 규칙을 2026-11-06 에 확정(source=kakao, medium 4종, campaign kebab, content=버튼, term=A/B, https). 지금 UTM 만들기(/utm)는 광고·SNS 용 자유 입력기라 이 규칙을 몰라 직원이 손으로 맞춰야 한다. 규칙을 화면이 대신 지키게 하고, 버튼 여러 개짜리 메시지 링크를 한 번에 만들게 한다.

## 1. 목표
- CRM 메시지 링크는 입력 4개(발송 수단·캠페인·버튼 목록·A/B)로 끝난다. source·medium·content·term 은 화면이 채운다.
- 규칙 위반은 만들기 전에 잡고 고친 값을 바로 제안한다.
- 같은 규칙을 CRM 메시지 엑셀 가져오기 검사와 공유한다(검사 로직 한 벌).
- 결과를 CRM 엑셀 양식의 칸 모양 그대로 복사해 붙일 수 있다.

## 2. 지금과 달라지는 것
| 구분 | 지금 | 바뀐 뒤 |
|---|---|---|
| 용도 | 광고·SNS 한 가지 | 맨 위에서 '광고·SNS' / 'CRM 메시지' 선택 |
| CRM 링크 입력 | source·medium·campaign·content·term 전부 손으로 | 발송 수단 4버튼 → source·medium 자동. 버튼명 적으면 content 슬러그 자동 |
| 버튼 여러 개 | 링크마다 처음부터 다시 | 버튼 목록(이름+URL) 적으면 N개 한 번에 생성 |
| A/B | term 에 직접 | 토글 하나(a/b) |
| 규칙 검사 | 없음 | 소문자·하이픈·날짜 접미·https·medium 4종·content 필수(버튼 2개 이상) 검사 + 자동 고침 |
| 캠페인 중복 | 모름 | 다른 CRM 메시지가 쓰는 캠페인이면 경고(같은 메시지 재생성은 통과) |
| 결과 복사 | URL 한 줄 | 버튼별 표 + '엑셀 칸으로 복사'(링크 URL 칸 줄바꿈 묶음·캠페인·매체) |
| 히스토리 | 한 종류 | 용도 열(광고/CRM)로 구분, CRM 은 메시지명 표시 |
| 광고·SNS 모드 | 그대로 | 공통 최소 규칙만 추가(https 강제, 소문자, 공백→하이픈). 기존 값·히스토리는 손대지 않음 |

## 3. 원칙
- 규칙은 한 곳(`app/lib/utm-rules.ts`)에만 둔다. 화면·가져오기·비서 설명이 전부 이 파일을 읽는다.
- React 로 다시 쓴다(`app/utm/page.tsx`). 정적 HTML(`public/utm-builder.html`)과 iframe 은 삭제하고 sync-tokens 대상에서 뺀다. 규칙 모듈을 화면과 서버가 같은 import 로 쓴다. 공용 컴포넌트·b2b.css 토큰을 쓰고 전용 CSS 는 `.utm-*` 접두사.
- 자동 고침은 제안만 한다. 직원이 [고친 값으로] 를 눌러야 바뀐다.
- 슬러그 사전은 직원이 키운다. 처음엔 공지의 슬러그 20여 개로 시작하고, 새 한글 버튼명을 영문으로 바꿀 때마다 사전에 쌓인다.
- 폼 칸 밑 고정 안내 문구는 넣지 않는다. 검사 결과(동적)만 칸 아래 뜬다.

## 4. 설계

### 4-1. 규칙 모듈 `app/lib/utm-rules.ts`
- 상수: `CRM_SOURCE = "kakao"`, `CRM_MEDIA = [alimtalk-cafe24, brandmessage-cafe24, alimtalk-naver, brandmessage-naver]`(표시명: 알림톡·공식몰 등), 날짜 접미 정규식(`[-_]?\d{4}$`, `_26\d{2}`), 슬러그 규칙 `^[a-z0-9]+(-[a-z0-9]+)*$`.
- 함수: `slugify(ko)`(사전 조회 → 영문 소문자·하이픈), `checkCrmUtm({source, medium, campaign, content[], term})` → `{ ok, issues: [{field, msg, fix}] }`, `buildLinks(baseUrls[], params)` → 버튼별 URL(https 강제, 기존 쿼리 보존, UTM 덮어쓰기).
- 엑셀 가져오기 검사(`/api/crm/messages/import`)도 같은 `checkCrmUtm` 을 줄마다 호출.

### 4-2. API
- `GET /api/utm/settings` 응답에 `crmRules`(매체 4종·슬러그 사전) 추가. 추가 호출 없음.
- 검사는 화면에서 규칙 모듈로 즉시 한다(API 없음). 캠페인 중복만 `GET /api/utm/campaigns`(crm_messages 의 캠페인·매체·메시지명 목록, 화면 열 때 1회)로 확인.
- `PUT /api/utm/settings` 에 `contentSlugs`(사전) 저장 추가.

### 4-3. 화면(`app/utm/page.tsx`, 기존 기능 전부 이식: 즐겨찾기·소스/매체 관리·히스토리 100건·검색·CSV 내려받기·CSV 대량 추가·QR)
- 맨 위 용도 선택 세그먼트: [광고·SNS] [CRM 메시지]. 선택은 브라우저에 남는다.
- CRM 모드 카드:
  1. 발송 수단: 4개 칩(알림톡·공식몰 / 브랜드메시지·공식몰 / 알림톡·네이버 / 브랜드메시지·네이버).
  2. 캠페인: 입력 + 기존 CRM 메시지 캠페인 자동완성. 한글을 치면 슬러그 제안이 옆에 뜬다.
  3. 버튼 목록: 행 추가 방식(버튼명, 링크 URL). 버튼명 옆에 content 슬러그가 자동으로 채워지고 고칠 수 있다. '채널추가'처럼 링크 없는 버튼은 URL 비우면 건너뛴다. 외부 도메인(instagram·naver.com·kakao.com)은 'UTM 안 붙임' 표시.
  4. A/B: 끔 / a / b.
  5. [링크 만들기] → 검사 → 문제 있으면 칸별 빨간 메시지 + [고친 값으로] 버튼. 통과하면 결과 카드.
- 결과 카드: 버튼별 표(버튼명 · content · URL · 복사). 아래 세 버튼: [전체 복사] [엑셀 칸으로 복사] [저장]. '엑셀 칸으로 복사'는 탭 구분 한 줄(링크 URL 칸은 줄바꿈 묶음, 캠페인, 매체)로 클립보드에 넣어 CRM 양식 행에 붙이면 세 칸이 채워진다.
- 히스토리: 용도 배지, CRM 은 캠페인·버튼 수 표시. 검색은 그대로.
- 광고·SNS 모드: 기존 화면 그대로. 미리보기에 https·소문자·하이픈 경고만 추가.

### 4-4. 데이터
- 마이그레이션 161(CRM 가져오기와 묶음): `utm_links` 에 `purpose text default 'ad'`, `crm_campaign text default ''` 추가. `utm_settings` 에 key `content_slugs`(사전). `crm_messages` 쪽 변경(본문·링크 목록·utm_term)은 CRM 가져오기 기획에서 같이 정한다.
- 미적용 환경 폴백: 새 열이 없으면 용도 없이 저장(기존 동작).

### 4-5. 가이드·비서
- `/utm` 가이드 항목에 CRM 모드 단계 추가, 규칙 표 한 줄 요약.
- SharePoint '[비서] 데이터 해석 기준'에 UTM 규칙 한 단락 추가(비서가 캠페인명을 물으면 규칙대로 답하게).
